Liquid Distortion

A premium React component that creates an interactive liquid distortion effect on images. The distortion follows the cursor with smooth motion, making it perfect for modern portfolios, agency websites, landing pages, and creative experiences.

✨ Features

- Interactive liquid distortion effect
- Smooth cursor-based animation
- Customizable intensity, resolution, and cursor size
- Responsive design
- Built with React, TypeScript, and Vite
- Easy to integrate into existing projects

📦 Tech Stack

- React
- TypeScript
- Vite

🚀 Getting Started

Install dependencies

npm install

Start the development server

npm run dev

Build for production

npm run build
